Main sections
1. Header and navigation
The header stays fixed at the top while the user scrolls. It includes:

Restaurant logo: Spice Garden

Menu links: About, Menu, Experience, Visit, Reservations

A gold Reserve a Table button

A hamburger menu on mobile devices

2. Hero section
The first screen introduces the restaurant with:

Large heading: “Refined flavors, crafted with intention.”

Short description of the restaurant

Two buttons: Explore the Menu and Book a Table

Trust badges such as guest rating, vegetarian options, private dining, and takeaway

Statistics: years of hospitality, signature dishes, guest rating, and fresh preparations

3. About section
This section explains the restaurant’s story and values. It highlights:

Chef-led seasonal menu

Fresh, locally sourced ingredients

Vegetarian, vegan, and gluten-friendly options

Private dining and event hosting

4. Signature menu
The menu uses photo cards instead of a plain text list. Each dish includes:

A real food photograph

Dish name

Short description

Helpful tag such as “Vegetarian,” “Seasonal,” or “Great for sharing”

Dishes shown include Butter Chicken, Paneer Tikka Masala, Tandoori Platter, Lamb Rogan Josh, Mango Lassi, and a Chef’s Curry Special. Prices are not displayed.

Restaurant address

“Your table is waiting”

9. Footer
The footer contains:

Copyright text

Links to Menu, Visit, Reservations, and Privacy Policy

UX and accessibility
The website was designed with user experience in mind:

Fully responsive layout for phones, tablets, and laptops

Mobile hamburger navigation

Skip-to-content link for keyboard users

Visible focus outlines for accessibility

Descriptive alt text for all images

Clear buttons and simple navigation

Fast loading because it uses one HTML file with no heavy frameworks

Technology used
HTML5 for page structure

CSS3 for dark theme, layout, animations, and responsiveness

Vanilla JavaScript for the mobile menu toggle

CSS Grid and Flexbox for modern responsive layouts

No React, Bootstrap, jQuery, or build tools required
